# 📘 HTML Cheat Sheet  
A complete and clean reference of HTML tags with examples and outputs.

This project is a pure HTML educational page created to help beginners and students understand **all the major HTML elements**, with practical examples and real rendered results.

No CSS.  
No JavaScript.  
Only clean, semantic HTML.

---

## 📖 What’s Inside

The page includes:

### ✔ Basic Structure  
- `<!DOCTYPE html>`  
- `<html>`  
- `<head>`  
- `<title>`  
- `<meta>`  
- `<link>`  
- `<body>`  
- Comments

### ✔ Text & Headings  
- `<h1>`–`<h6>`  
- `<p>`, `<br>`, `<hr>`  
- `<b>`, `<strong>`, `<i>`, `<em>`, `<u>`, `<mark>`, `<small>`  
- `<pre>`, `<blockquote>`, `<q>`  
- `<abbr>`, `<cite>`, `<dfn>`

### ✔ Lists & Grouping  
- `<ul>`, `<ol>`, `<li>`  
- `<div>`, `<span>`  
- `<section>`, `<article>`, `<header>`, `<footer>`, `<main>`  
- `<address>`

### ✔ Images & Media  
- `<img>`  
- `<figure>`, `<figcaption>`  
- `<audio>`, `<video>`, `<source>`
